# Tic-Tac-Toe

An **interactive Tic-Tac-Toe game** built in Python featuring a clean interface, support for 2-player or AI modes, and robust win/draw logic.

## 📌 Project Overview
This repository contains a Python implementation of the classic **3x3 Tic-Tac-Toe** game. It is designed to be lightweight, easy to run, and well-structured for beginners and portfolio showcases.

## ✨ Features
* **Game Modes:** Play against a friend locally or challenge the computer.
* **Input Validation:** Prevents out-of-bounds choices or overwriting already occupied grid cells.
* **Win & Draw Detection:** Automatically evaluates horizontal, vertical, and diagonal lines for a winner, or declares a tie if the board fills up.
* **Clean Interface:** Clear visual representation of the grid state after every turn.
* **Easy Restart:** Option to reset and play multiple rounds without restarting the script.

## 🚀 Getting Started

### Prerequisites
* **Python 3.x** installed on your system.

### Installation & Running
1. Clone the repository:
   ```bash
   git clone https://github.com
   cd tic-tac-toe
   ```
2. Run the game:
   ```bash
   python main.py
   ```

## 🕹️ How to Play
* Player `X` always goes first.
* Enter your move by selecting the corresponding grid number or coordinates (e.g., rows/columns or 1–9).
* Align **three of your symbols** (horizontal, vertical, or diagonal) to win the match.
